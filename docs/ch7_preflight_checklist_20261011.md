## 4.5 运行次数与可复现性（**硬要求，2026-10-11 实测后追加**）

**事实**（`tools/ch7_gate_records.mjs` 的组内判定给出）：同一 URL、同一协议、同一臂重复跑，fps 并不复现：

| 组 | 协议 | 次数 | fps 极差 |
|---|---|---|---|
| `u=outchk6-gls`（本文臂，桌面） | `frames=20 warmup=10 runs=1 msgchannel` | 3 | **426.4 / 377.4 / 199.4（×2.14）**，`cpu_ms` 2.3 / 2.6 / 5.0 |
| `u=side2-1-ours`（本文臂，手机，取图） | `frames=2 warmup=0` | 3 | 37.0 → 87.7（×2.37） |
| `u=sideflux-2-flux`（Flux，手机，取图） | `frames=2 warmup=0` | 4 | 87.7 → 253.2（×2.89） |

**要求**：

1. **每个主数据组至少跑 3 次**（同一 URL、连续跑、期间不换页面不切后台），报告 **中位数 + 极差**；单次结果**不得**作为数字。
2. **组内 `max/min ≤ 1.5` 才可用**；超了 ⇒ 该组数字判为不可复现，**整组重跑**（并先排除热/后台/频率原因）。
3. **取图协议（`frames=2`）的 fps 仅供并排图标注**，不作为性能数字 —— 2 帧窗口的噪声可达 ×2.4–3.9。
4. 任何"同 URL 两组数字相差 >1.5×"的情况，**先怀疑可复现性**，再怀疑实现差异。
