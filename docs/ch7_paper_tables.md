**结论（写论文用）**
1. **主表（性能）只放我们自测两臂**（同会话 ABAB、同分辨率、同协议 B）——这是唯一严格同口径的一组；
2. **Flux 论文 Table 1/2/3 可以引用**（它§5.1 的离屏协议与我们的协议同族，且 Mip360 上我们复现到 148.1 vs 论文 139–147），但必须：

   - 在表注写明：**T&T/DB 两列我们的自测比其报告值低 19–28%**，观众需知道这一偏差；
3. **质量对比（表 7-F）可以写"本文在三个数据集上略优于 Flux-GS 报告值"**，但注明：跨论文、非同一评测脚本、点数/存储上有差异（Flux 更小）。
